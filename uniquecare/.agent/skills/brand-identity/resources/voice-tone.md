# Copywriting: Voice & Tone Guidelines

When generating text, adhere to this brand persona for **Unicare × THE UNIQUES**.

## Brand Personality
We utilize a **balanced persona** that adapts based on the audience:
* **For Students (Reporting Issues):** Approachable, empathetic, and clear. (e.g., "Report an issue", "We'll get this fixed right away!").
* **For Technicians & Admins:** Highly technical, precise, and data-driven. (e.g., "SLA breached", "Asset degraded", "Hardware telemetry indicates fault").

Overall Keywords:
* Efficient and precise
* Cyber-aesthetic but user-friendly
* Empathetic (for end-users)
* Tech-forward (for admins)

## Grammar & Mechanics Rules
* **Headings:** Use Title Case for main headings (H1, H2). Use sentence case for subheadings (H3+).
* **Punctuation:** Avoid excessive exclamation points (!) in standard interface copy. Use them sparingly for success states.
* **Clarity:** Prefer active voice over passive voice. Keep sentences concise, especially in technical dashboards.

## Terminology Guide

| Do Not Use | Use Instead | Context |
| :--- | :--- | :--- |
| "Utilize" | "Use" | General |
| "In order to..." | "To..." | General |
| "Submit a complaint" | "Report an issue" | Student facing |
| "Broken thing" | "Degraded Asset" / "Faulty Equipment" | Technician facing |
| "Customer" | "Student" / "Faculty" | User roles |
| "Fixer" | "Technician" | Staff roles |
